🐾 Paw Pet E-Commerce — Wireframe

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio de UX/UI Design,
com o objetivo de criar um wireframe de média fidelidade para a página
inicial de um e-commerce pet.

## 🎯 Objetivo

Criar uma experiência de navegação simples, intuitiva e organizada,
facilitando o acesso dos usuários aos principais produtos e categorias
de uma loja virtual para pets.

## 💡 Conceito

A proposta consiste em uma página inicial de um e-commerce voltado
para produtos para animais de estimação.

A página apresenta categorias de produtos, ofertas, informações sobre
a marca e outros elementos importantes para a experiência de compra.

## 🖥️ Estrutura da página

- Header
- Hero
- Categorias
- Ofertas da semana
- Conheça nossa marca
- Por que comprar?
- Footer

## 🧠 Conceitos de UX/UI aplicados

- Hierarquia visual
- Arquitetura da informação
- Lei de Hick
- Lei de Fitts
- Heurísticas de Nielsen
- Leis de Bastien
- Princípios da Gestalt
- Consistência e padronização
- Reconhecimento em vez de memorização

## 📚 Desafio

Projeto desenvolvido como atividade prática para aplicação dos
conceitos de psicologia do design e usabilidade estudados no curso.
